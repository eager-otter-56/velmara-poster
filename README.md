A travel poster for a place that does not exist: VELMARA, a white
terraced cliff-city above a golden sea of clouds, its tall lighthouse
watching over a sailing ship that crosses the clouds at dawn. The
place's name is set into the picture in cream display type on a deep
teal band, in the manner of a 1930s travel poster.

## Run it

```sh
python3 main.py
```

Writes the committed `entry.png` to `/output/entry.png`, unchanged.
